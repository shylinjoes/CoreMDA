CoreMDA: Webtool for Core Microbiome Identification and Differential Abundance analysis

### Description of the Repository Contents

- **Data/**: This folder contains the OTU table, metadata table, and taxonomy table used for analysis.

- **Core_Microbiome_iden.R**: This script contains the code for data preprocessing, data filtering, normalization, diversity analysis, exploratory analysis, and core microbiome identification.

- **SIG_test_complete.R**: This script contains the code for testing the statistical significance of the identified core microbiome using the complete dataset.

- **SIG_test_group.R**: This script contains the code for testing the statistical significance of the identified core microbiome across different groups.

- **DAA_analysis.R**: This script contains the complete code for differential abundance analysis and visualization.
